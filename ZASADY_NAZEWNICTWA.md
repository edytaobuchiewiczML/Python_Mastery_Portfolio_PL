# ZASADY NAZEWNICTWA W PYTHONIE

## WIELKIE_LITERY_Z_PODKREŚLNIKIEM → STAŁE (NIE ZMIENIAJ)
WIELKIE LITERY Z PODKREŚLNIKIEM (np. MAX_SPEED, PI, DATABASE_URL) oznaczają STAŁE — wartości, których NIE ZMIENIAMY w trakcie działania programu. 
To konwencja przyjęta przez programistów Pythona, mówiąca: "tej wartości nie modyfikuj".
MAX_ROZMIAR = 1000
DOMYSLNA_NAZWA = "admin"
SCIEZKA_BAZY = "/data/baza.db"

## male_litery_z_podkreslnikiem → ZMIENNE (MOŻNA ZMIENIAĆ)
MAŁE LITERY Z PODKREŚLNIKIEM (np. user_name, total_sum, file_path) oznaczają ZMIENNE — wartości, które MOGĄ BYĆ ZMIENIANE w kodzie.
licznik = 0
nazwa_uzytkownika = "jan_kowalski"
suma_elementow = 0
